## 构建、验证与启动

使用仓库的.NET 10 SDK，在普通权限PowerShell执行：

```powershell
./tools/CourtPreview/Build.ps1 -Output C:/Temp/furina-court-interactive-preview
```

该脚本只发布普通自包含工具并运行 `CourtPreview.exe --verify`，**不Show窗口**。输出 `verification/` 中包含各页/三游子页在1600×900、960×500的顶/底部截图，以及助手460×720、360×460；绑定错误、逐入口移除清单一起保存。`package-sha256.json`记录发布物散列。

仅总控/用户决定显示窗口时：

```powershell
C:/Temp/furina-court-interactive-preview/CourtPreview.exe --interactive
```

没有默认启动行为；必须显式选择参数。工具拒绝管理员权限和带真实执行许可的构建。每次自行创建新的 `TEMP/furina-court-demo-随机号`，在控制台打印绝对路径，初始化空白SQLite后关闭连接，不接收任意档案目录参数。交互启动先在该临时目录完成离屏检查，再显示主窗。没有App.OnStartup、MainViewModel、AccountViewModel、AssistantViewModel或业务服务实例，也不调用InitializeAsync。DEMO账号/记录是纯内存属性袋，字段描述来自编译进来的参数目录，素材只来自本包。

## 操作边界

- 允许：原Tab页面/子页切换、滚动、折叠、列表本地选择、文本框本地编辑、窗口缩放关闭；宿主按钮只显示合成助手。没有生产代码后置事件。
- 原业务Button/CheckBox/ComboBox/PasswordBox/Hyperlink一律禁用，Command/CommandParameter/CommandTarget、事件属性、输入/命令绑定和事件触发器在加载前逐项移除，API设置子树不展示。保留的默认WPF滚动和折叠操作仅改变UI；文本编辑只写内存DTO。
- 扫描、导入、保存、导出诊断、路径浏览、联网、发送与真实执行均没有可调用入口；不依靠RefusingProcessSupervisor拦截，因为不注入业务运行服务。
- `removed-entries.txt`逐项记录来源文件、行号、原值和强制禁用前的产品状态；未知未移除事件因无代码后置而加载失败，工具不继续显示。
- 自检遍历逻辑/可视树及模板：拒绝残留业务命令、启用的业务按钮、输入/命令绑定、业务ViewModel；附禁用按钮/残留命令负例。验证页面、折叠、输入与滚动底部、数据库哈希不变、未创建窗口句柄。
- 关闭主窗口退出，助手只隐藏/显示，退出时关闭并清理自己的唯一临时目录；删除前确认它是TEMP直接子目录和专用前缀。不删除其它目录。进程被强杀/机器断电时不能保证执行finally，控制台的临时目录可能残留，需由总控核对后清理。

## 视觉有效性与限制

永久红色标识“视觉验收 · DEMO · 业务禁用”。标识和宿主助手按钮占用额外高度，另加系统窗口边框供拖拽/缩放/关闭。业务控件的灰色/透明度是宿主强制禁用效果，不是产品原状态；不能用这些截图判定产品可用/禁用对比度。首页/参数/账号/设置应与 `artifacts/tests-b/court-grid-default/` 同尺寸DEMO图对照，预期差异还包括合成文字、无真实检测/最近批次、任务只读、无API设置。

宿主复制了06fa8e2的纯布局宽度公式；没有生产输入会话、全局热键、助手窗口拖拽代码、自动工作区裁剪或真实业务回调。它只能验收视觉布局与上述本地交互，不认证生产事件路由、权限、游戏焦点、真实账号切换或任何任务结果。助手消息全合成，输入不发送；人工窗口交互仍待总控启动检查。

本工具是独立任务，DeepSeek审查只覆盖tools/CourtPreview新增实际差异；不能扩大到之前未复审的美术改动。
