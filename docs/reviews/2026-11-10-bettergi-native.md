## 本轮已修复

1. 正式入口创建隔离发行包、最小化 config 丢失原引擎设置，且在引擎开始前自行操作地图。改为原 BetterGI 安装 + 原账号完整 profile + 原脚本库/队伍/捕获/传送设置。移除地图库存 OCR、等待器、输入桥接、模板图片及相应测试。取消正式入口的发行压缩包依赖。
2. 原生任务结束后默认“无”会留下引擎，不能安全切号。只临时修改账号 profile 的 CompletionAction=关闭软件，运行结束/失败后恢复。没有修改任务顺序、地区、树脂保留量、队伍或全局 config。
3. 上游 OnOneKeyExecuteAsync 无条件 SaveConfig，会重新序列化 profile。恢复只还原自己改过的字段，保留原版其他更新；结束后动作被另行修改时阻止覆盖。持久化字段合并前后摘要，使两处原子移动中断可恢复。原格式未改变时仍逐字节恢复。
4. 默认单账号任务限时从旧验收的 5 分钟改为 30 分钟，从交给引擎起计时；正常多账号批次没有共享短倒计时。用户停止仍有界清理，清理失败不再无限等待 verdict。
5. 结果按本次 PID/启动时间/配置和任务序列的上游日志判定，须有流程结束、每日奖励识别与合成尝试或无需合成记录，无冲突/错误且引擎退出、配置恢复确认后才能切号。明确合成数量未独立核验，不把退出码或测试通过冒充游戏任务成功。
6. 修正界面对秘境“预算按账号保存”的执行暗示：目前预算暂存，秘境执行仍阻止，不能静默用全局配置代替账号预算。

本轮深审覆盖 BetterGI 首页→账号批次→登录切号→原引擎→结果→恢复链，以及跨游戏顺序与配置作用域；不等于对所有游戏和全仓库无遗漏审计。秘境按账号预算映射、更多上游任务、其他引擎全面审查仍有工作。用户两账号合成→领奖→切号实机验收待进行，未由代理运行游戏。
