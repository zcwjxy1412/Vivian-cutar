> ⚠️ **仅模拟模式的开发构建。** 本版本**不包含任何真实游戏自动化**：不会启动游戏、引擎或任何其他程序，不读写游戏文件，也不操作键盘鼠标。“模拟队列”中的所有结果都带【模拟】标签，不代表任何游戏日常的真实完成情况。

### M2 新增内容

- **执行内核**：严格串行调度；执行阶段、任务结果、清理结果三层状态相互独立；只有明确的完成证据才判为成功
- **紧急停止**：立即生效，没有倒计时
- **运行记录与崩溃对账**：VIvian 意外退出后，中断的运行会标记为“结果未知”，在你确认之前不会开始新队列
- **单实例保护**：同一个数据目录同时只能运行一个 VIvian
- **“模拟队列”页面**：可以为每款游戏选择一种模拟情形（完成、无证据、失败、卡死、无法确认清理），体验调度、停止和结果判定的流程

### 升级说明

首次运行时，数据库会自动从 v1 升级到 v2，原有的引擎路径和自检记录都会保留。升级之后，0.1.0 版会拒绝打开这个数据库（不会损坏数据）。
