# M5 每日实训 Windows 实测

此开发包只开放 March7thAssistant v2026.10.31 的 `daily`。真实游戏和账号操作必须由你本人在自己的 Windows 电脑上确认。CI 与 WPF 冒烟只证明程序构建、自检和模拟流程可用，不能证明游戏任务成功。

1. 从本 PR 的成功 Windows CI 下载 `VIvian-M5-DailyTest-win-x64`，解压到独立目录并运行 `VIvian.exe`。不要沿用 M4 的数据目录或一次性许可。
2. 在“引擎管理”填写已安装的固定版目录与官方 `March7thAssistant_full.zip`，点击核对；身份必须显示已验证。
3. 在原软件中关闭“成功后暂停”，开启“失败后退出”。在“任务管理”选择星铁，读取配置，检查当前值。可先修改 `daily_enable` 等已开放的布尔值，保存前查看差异与备份提示，再从原软件修改同一字段，确认 VIvian 自动刷新。运行中请不要修改配置。
4. 在“真实任务测试”确认选中“每日实训”，检查账号已登录、任务所需配置、安装身份与上次运行的清理状态。仅当你愿意执行本次真实任务时勾选本次确认并点击开始。UAC 由你本人核对并处理。
5. 查看启动、运行日志、结束结果与清理状态。可点击“紧急停止当前任务”；清理无法确认时后续运行会阻断。退出码为 0 但没有实训 500 分证据时，应显示“结果未知”。
6. 如遇阻断，导出诊断报告并记录界面提示、时间、是否接受 UAC、上游日志中的本次 RunId。请勿发送未脱敏的 `config.yaml`、账号信息或游戏截图。

BetterGI 和 OneDragon 当前只提供任务目录、配置位置与只读状态。OneDragon 多账号实例尚未绑定，不能写入配置或执行真实任务。
