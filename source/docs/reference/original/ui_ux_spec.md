# Vivian V1.0 桌面应用 UI/UX 设计规范与交互说明 (UI_UX_SPEC.md)

**文档路径**：`docs/requirements/UI_UX_SPEC.md`  
**设计语言**：Microsoft Fluent Design System (Windows 11 Mica / Acrylic 材质) + 游戏主题语义微色彩  
**目标平台**：Windows 10 (21H2+) / Windows 11 x64，支持 100% ~ 250% DPI 无损矢量缩放、深浅双主题实时切换与系统托盘常驻。

### 1.2 字体层级与排版尺度
- **中文字体栈**：`"Microsoft YaHei UI", "PingFang SC", sans-serif`
- **等宽日志/代码字体**：`"Cascadia Mono", "Consolas", monospace`
- **字号层级**：
  - 页面大标题（Page Title）：`22pt SemiBold`
  - 卡片主标题（Card Header）：`15pt SemiBold`
  - 正文与设置项标签（Body）：`13pt Regular`
  - 辅助说明文字（Caption）：`11pt Regular`（次级前景色 `#9CA3AF` / `#6B7280`）
  - 实时控制台日志流（Log Console）：`12pt Monospace`（行高 `1.45`）

### 1.3 窗口布局与响应式缩放规范
- **默认窗口尺寸**：`1160 × 760 px`；**最小窗口尺寸**：`960 × 640 px`。
- **布局结构**：采用经典的 **左侧紧凑型垂直导航栏（NavigationView，宽度 `210px`，小尺寸窗口自动折叠为 `56px` 图标栏） + 顶部全局运行状态横幅（高度 `48px`） + 右侧主内容滚动区**。
- **高分屏 DPI 缩放**：全矢量 `Fluent System Icons` 图标，所有容器基于 `Grid` 比例星号（`*`）与自适应 `UniformGrid` / `WrapPanel` 布局，在 1080p（100%）、2K（125%/150%）、4K（200%）显示器下均不出现文字截断或横向滚动条。

### 页面 1：首页概览与一键启动 (`HomeOverviewPage`)
- **顶部核心操作栏（Hero Action Bar）**：
  - 左侧：超大号主按钮 **「▶ 一键启动三游日常」**（点击后立即将勾选了“加入一键队列”的游戏按拖拽顺序送入串行执行队列，并自动跳转或展开底部实时监控抽屉）。
  - 中部：**编排顺序快捷拖拽胶囊**（默认：`① 绝区零` $\rightarrow$ `② 崩坏：星穹铁道` $\rightarrow$ `③ 原神`，支持鼠标左右拖拽调整先后顺序）。
  - 右侧：**队列完成后全局动作下拉框**（`仅关闭游戏` [默认] / `关闭游戏并退出 Vivian` / `系统睡眠` / `60秒倒计时关机`）与 **定时启动开关**（如 `每日 04:15 自动执行`）。
- **中部三游戏状态卡片矩阵（3 列等宽卡片）**：
  - 每张卡片展示：游戏图标与名称、绑定引擎当前版本与兼容性徽章（如 `v0.66.0 [已验证]`）、今日日常是否已执行、上次运行耗时、核心日常子任务快捷勾选摘要，以及底部的 **「▶ 单独运行」**、**「⚙ 任务配置」**、**「↗ 打开原版界面」** 三个按钮。
- **底部 환경预检状态栏（Pre-flight Check Bar）**：
  - 实时显示：`管理员权限：已获取 ✅` | `屏幕分辨率：1920×1080 (16:9) ✅` | `HDR 状态：已关闭 ✅` | `引擎路径校验：全部通过 ✅`。若任意一项异常（如检测到开启了 Windows HDR），直接高亮黄色警告并提供「一键修复/查看原因」。

### 页面 2：三游戏独立任务设置 (`GameTaskSettingsPage`)
顶部采用 Pivot / Segmented 分段选项卡切换 **「原神 (BetterGI)」**、**「崩坏：星穹铁道 (March7th)」**、**「绝区零 (OneDragon)」**。每个子页面严格遵循 **“高频日常开关可视化 + 复杂底层配置一键唤起原生 GUI”** 的设计原则：

1. **原神（BetterGI）子页面**：
   - **配置组选择**：读取 `User\OneDragon\*.json` 下拉选择（如 `默认配置`）。
   - **日常子任务开关与拖拽排序列表**：`领取邮件`、`合成树脂`（附合成台地区下拉：枫丹/稻妻/璃月/蒙德）、`自动秘境`（附秘境名称选择与周日序号选择）、`自动首领讨伐`、`自动幽境危战`、`自动刷地脉花`、`领取每日奖励`（附冒险家协会地区下拉）、`领取尘歌壶奖励`、`自动七圣召唤`，以及已挂载的 `ScriptGroup` 配置组开关。
   - **前置与超时设置**：单次最大超时时间（默认 45 分钟）、启动前自动关闭残留 BetterGI 进程开关（强制开启）。
   - **高级配置入口**：「打开 BetterGI 原生设置（配置配队/战斗策略/地图追踪路线）」。

2. **崩坏：星穹铁道（March7thAssistant）子页面**：
   - **执行模式选择**：`完整运行 (main)` [推荐] / `日常 (routine)` / `仅每日实训 (daily)` / `仅清体力 (power)`。
   - **日常与体力配置组**：`启用每日实训 (daily_enable)`、`启用清体力 (power_enable)`、`启用培养目标自动匹配 (build_target_enable)`、默认副本类型（拟造花萼金/赤、凝滞虚影、侵蚀隧洞、饰品提取）与副本名称下拉、`使用后备开拓力`、`使用燃料`、`使用支援角色`、`自动领取委托与邮件奖励`。
   - **周常自动化开关组**：`优先完成历战余响 (3次/周)`、`差分宇宙每周积分奖励`、`货币战争每周积分奖励`、`逐光捡金（混沌回忆 / 虚构叙事 / 末日幻影）`、`每周自动清理四星遗器`、`包含锄大地 (Fhoe-Rail)`。
   - **运行环境模式**：`Windows 本地前台模式` / `Windows 本地后台模式 (v2026.10.31+)` / `云·星穹铁道无窗口模式`。
   - **首次免责声明状态提示**：若 `m7a.exe --status` 检测到 `first_run_completed == false`，显示醒目横幅：「首次使用需在三月七小助手界面内本人确认免责声明」并提供「立即打开确认」按钮。

3. **绝区零（ZenlessZoneZero-OneDragon）子页面**：
   - **账号实例选择**：支持勾选单实例（默认 `实例 01`）或多实例连续运行（对应 `-i 1,2` 参数）。
   - **一条龙任务清单开关**：展示每日签到、录像店营业、咖啡店、体力刷本、活跃度奖励、丽都城募、恶名狩猎、迷失之地、式舆防卫战、驱动盘拆解等开关状态。
   - **输入与后台模式提示**：显示当前虚拟手柄（`ViGEmBus`）检测状态；提供「打开绝区零一条龙原生界面配置预备编队与体力计划」按钮。

### 页面 3：执行队列和运行监控 (`ExecutionMonitorPage`)
- **左侧/上方：串行执行队列流水线（Pipeline Stepper）**：
  - 清晰展示当前批次队列中的三个阶段卡片（如 `[1. 绝区零: 已完成 12m30s ✅]` $\rightarrow$ `[2. 星穹铁道: 运行中 - 正在执行清体力 (3/5) 🔄]` $\rightarrow$ `[3. 原神: 排队等待中 ⏳]`）。
  - 提供队列级控制按钮：**「⏸ 暂停队列（当前游戏跑完后挂起）」**、**「⏭ 跳过当前游戏并进入下一个」**、**「⏹ 立即终止全部任务 (Ctrl+Alt+F12)」**。
- **右侧/下方：实时双轨监控终端（Live Telemetry & Log Console）**：
  - **进程健康度仪表盘**：显示当前活跃引擎 PID、关联游戏 PID、当前已运行时间 / 超时倒计时、距离上次日志输出的心跳秒数（如 `心跳正常：2 秒前`）。
  - **结构化实时日志流**：支持按 `全部 / 仅进度 / 警告与错误` 过滤，自动高亮 `[INF]`、`[WRN]`、`[ERR]`，支持「自动滚动到底部」、「复制选中日志」、「打开引擎原日志目录」。

### 页面 4：引擎安装与版本更新 (`EngineManagerPage`)
- 三张纵向展开式引擎管理卡片（BetterGI / March7thAssistant / ZZZ-OneDragon），每张卡片包含：
  1. **安装状态与路径**：显示当前绑定路径，支持 **「一键下载并初始化安装」** 或 **「绑定本地已有目录」**（绑定 ZZZ-OneDragon 时实时校验是否包含中文或空格，若不合规立即红字拦截并给出修改建议）。
  2. **版本与兼容性状态矩阵**：
     - 显示 `当前本地版本`、`最新上游正式版`、`Vivian 兼容性评级`（🟢 已验证兼容 / 🟡 新版待验证 / 🔴 已知不兼容）。
     - **不自动更新保护开关**：默认开启「仅允许更新至已通过 Vivian 兼容性验证的版本」。当存在 🟡 待验证新版时，更新按钮显示为次级样式「手动尝鲜更新（需二次确认）」，并展示上游 Release Notes 原文。
  3. **配置快照与一键回滚区**：列出该引擎最近 5 次更新前自动生成的备份包（含版本号、备份时间、体积），点击 **「⏪ 一键回滚到此版本与配置」** 可在 10 秒内恢复至升级前状态。
  4. **下载源与加速设置**：支持切换 `GitHub 官方源`、`CNB 镜像源` 或填入 `Mirror酱 CDK` 极速下载。

### 页面 5：任务历史和错误日志 (`HistoryAndLogsPage`)
- **顶部统计概览**：最近 7 天一键日常成功率、累计节省时间估算、最近一次异常原因。
- **左侧批次历史列表**：按日期展示每次运行批次（状态徽章：全部成功 / 部分成功 / 失败 / 用户取消），点击展开三款游戏的单次执行详情（起止时间、退出码、完成子任务数）。
- **右侧错误诊断详情面板**：
  - 当选中失败记录时，自动展示：
    1. **故障时刻全屏快照预览图（Error Screenshot）**：直接看清当时游戏是卡在网络重连、版本更新提示还是实名/月卡弹窗。
    2. **异常日志上下文切片**：自动定位到报错前后 50 行日志。
    3. **智能排障建议卡片**：根据特征码（如退出码 `559`、OCR 预热异常、分辨率不匹配）给出具体修复步骤，并提供「导出脱敏诊断包（含日志与配置摘要，自动抹除 CDK 与 Webhook Token）」按钮。

### 页面 6：应用设置与风险提示 (`AppSettingsAndRiskPage`)
- **全局执行与热键设置**：
  - 全局紧急停止热键设置（默认 `Ctrl + Alt + F12`）。
  - 任务切换冷却等待时长（默认 `10 秒`）、单游戏日志静默看门狗超时阈值（默认 `8 分钟`）。
  - 任务开始前桌面顶部 5 秒防抢占倒计时提醒开关。
- **系统集成与托盘设置**：
  - 开机自动启动（通过 Windows 任务计划程序注册 `LogonType=InteractiveToken, RunLevel=Highest`，登录时静默提权启动不弹 UAC）。
  - 关闭主窗口行为：`最小化到系统托盘` [默认] / `直接退出程序`。
  - 外观主题：`跟随系统` / `深色模式` / `浅色模式`；UI 缩放比例微调（`100%` / `125%` / `150%`）。
- **开源合规与账号安全风险提示专区（常驻不可隐藏）**：
  - 完整展示三款上游项目的 GPL-3.0 开源协议声明、作者署名与官方仓库链接。
  - 醒目展示《账号安全与反作弊风险告知书》（首次启动 Vivian 时必须弹窗滚动阅读并勾选同意后方可进入主界面）。

## 3. 系统托盘（System Tray）与交互反馈细节
- **托盘图标动态状态**：
  - 空闲态：Vivian 标准静态图标。
  - 运行态：图标右下角叠加绿色呼吸圆点，鼠标悬停 Tooltip 实时显示：`Vivian 运行中：[2/3] 崩坏：星穹铁道 - 清体力 (已运行 08:24)`。
  - 异常态：图标右下角叠加红色感叹号，并触发 Windows 原生通知（Toast Notification）告知哪个游戏任务中断。
- **托盘右键菜单**：
  1. `显示主窗口`
  2. `▶ 一键启动三游日常`
  3. `⏹ 紧急停止当前任务 (Ctrl+Alt+F12)`
  4. `单独启动` $\rightarrow$ `[原神] / [星穹铁道] / [绝区零]`
  5. `打开日志目录`
  6. `退出 Vivian`
