# 预检失败的具体原因与处理入口

旧提示只显示计划编号和“条件或配置变化”，没有指出失败账号，也没有保留处理入口。本次把可信只读预检的原因枚举存入项目回执，区分会话阻断、待清理、待恢复、未保存修改、引擎未就绪、账号信息、任务、资源与配置版本变化。未知错误和执行阶段异常仍保持未确认清理，不放宽运行门禁。

首页显示游戏、账号、具体类别、已完成与跳过数量，提醒只重新确认未完成任务。按原因提供现有恢复、保存、安装检查及受影响账号设置入口；三游设置入口选择对应游戏及账号，不自动执行、修改任务或重放旧计划。

旧记录缺少新增字段时按 Unspecified 读取，明确说明旧记录未保存具体原因，而不是猜测用户改了配置。不回填历史记录，不进行数据库迁移。配置指纹变化仍可能来自上游运行记录变化，本提示不会将其归咎于用户。
