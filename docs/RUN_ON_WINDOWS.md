# 在 Windows 上运行 VIvian 开发版（0.3.0-dev）

> **开发版 · 模拟引擎。** 这个版本**不会**运行任何真实的游戏任务：不启动游戏，不启动 BetterGI、March7thAssistant 或 OneDragon，不读写游戏或引擎的配置。它能做的是：只读检查三个引擎的安装目录、核对星铁官方发行包，以及用模拟引擎演示调度、紧急停止和结果判定。

## 获取

1. 打开仓库的 Actions → **Windows validation**，进入最新一次成功的运行（对应要试用的分支或 PR）。
2. 在页面底部的 Artifacts 中下载 **VIvian-dev-win-x64**，解压得到 `VIvian-win-x64.zip`，再解压到一个新的空目录。
3. 需要 Windows 10/11 x64。这是自包含发布，不需要安装 .NET。程序未签名，SmartScreen 可能提示，选择“仍要运行”。

## 第一次使用

1. 运行 `VIvian.exe`。不需要管理员权限，也**不要**以管理员身份运行。
2. **引擎设置**：填写已经安装的引擎目录（可以只填一部分），点“保存路径”。VIvian 会自动只读检查。
3. **概览**：每个引擎显示一个状态。
   - **已验证（官方发行包）**：星铁的 `m7a.exe` 与已核对的官方发行包中的文件完全一致。只证明文件来源，**仍然不会运行它**。
   - **未验证**：找到了文件，但还没有用官方发行包核对。
   - **不支持**：版本不在 VIvian 的证据范围内，缺少必要文件，或者这个引擎尚未接入（原神 BetterGI、绝区零 OneDragon 目前都是这种情况）。
   - **未安装 / 未设置路径**、**无法访问**（路径超时、无法读取、经过链接或读取期间发生变化）。
4. 可选：在“引擎设置”底部选择从 [March7thAssistant 官方 Release](https://github.com/moesnow/March7thAssistant/releases/tag/v2026.10.31) 下载的 `March7thAssistant_full.zip`，点“核对官方发行包”。核对只读取文件、计算 SHA-256，不解压、不运行；结果只在本次运行中有效。
5. **模拟队列**：选择每款游戏的模拟情形，开始队列，随时可以紧急停止。结果都带【模拟】标签。

数据和日志在 `%LOCALAPPDATA%\VIvian`（日志在 `logs` 子目录）。遇到问题时，请附上日志和界面截图。

## 已知限制

- 真实任务执行没有开放；UAC、提权进程归属、真实引擎行为都还没有在桌面上验证。
- 官方发行包核对只支持 v2026.10.31 的 `March7thAssistant_full.zip`；7z 和更新包只能确认是官方文件，无法据此核对安装目录。
