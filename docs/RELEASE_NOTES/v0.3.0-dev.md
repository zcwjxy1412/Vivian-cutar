> ⚠️ **开发版：模拟引擎 + 只读引擎检查。** 本版本**不包含任何真实游戏自动化**：不启动游戏，不启动 BetterGI、March7thAssistant 或 OneDragon，不读写游戏或引擎的配置，也不操作键盘鼠标。

### 0.3.0-dev 新增

- **引擎就绪检查（只读）**：概览页显示三个引擎的状态（已验证 / 未验证 / 不支持 / 未安装 / 无法访问），并明确标注“真实任务执行：未开放”。路径中任何一段是链接都不跟随；读取时禁止其他程序写入；所有文件查询都有时限。
- **星铁官方发行包核对**：选择从官方 GitHub Release 下载的 `March7thAssistant_full.zip`（v2026.10.31），VIvian 将其 SHA-256 与官方公布的摘要比对，并从包内读取 m7a.exe 的摘要来核对安装目录。不解压，不运行。“已验证”只证明文件来源。
- **安全门禁**：有界的适配器调用与状态写入；按 RunId 发放的启动许可；停止时先撤销启动许可；运行状态不确定时阻断下一个队列。
- **关闭窗口时**先紧急停止，再等待队列记录最终状态（最长 30 秒）。
