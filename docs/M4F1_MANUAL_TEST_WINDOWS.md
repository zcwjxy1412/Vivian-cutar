# VIvian M4-F1 手动实测版 · 快速上手

这个版本可以**反复**做真实游戏测试，不用每次换新包。但每一次运行都要你本人确认，UAC 也由你亲自处理。

## 目前能测什么

- **只开放一项真实任务**：星铁 March7thAssistant v2026.10.31 的 `screen_test`（界面可切换性测试）。它会打开或连接星铁，依次切换约 39 个界面。
- **不开放**：定时或无人值守的真实执行、星铁的其他任务（每日实训、清体力等）、BetterGI（原神）、OneDragon（绝区零）。
- `screen_test` 成功只说明这次界面切换都有记录，**不代表日常已经完成**。

## 第一次使用

1. 把 ZIP 解压到一个**新文件夹**。保留里面的 `VIvian-M4-F1-ManualTest.marker`，否则程序会拒绝启动。
2. 双击 `VIvian.exe`。这个版本的数据存放在 `%LOCALAPPDATA%\VIvian-M4-ManualTest`，不会碰原来的 VIvian 数据，也不会碰 R3 单次测试包的数据。
3. 打开“引擎管理”页：
   - 在星铁那一栏填入安装目录：`E:\auto agent game\March7thAssistant-official-v2026.10.31\March7thAssistant_full`
   - 在“官方发行包”处填入：`E:\auto agent game\March7thAssistant_full-v2026.10.31.zip`，然后点“核对官方发行包”，等它显示“已验证”。
   - 核对通过后，安装目录会**自动保存**，下次打开不用再填。官方发行包每次启动程序都需要重新核对一次（要计算 SHA-256，需要一点时间）。

## 每次测试

1. **先手动打开星铁并登录账号**，确认能进入游戏。登录过期会导致测试失败，上次 R3 就是这个原因。
2. 打开“真实任务测试”页，看最上面的“当前状态”：
   - **未通过安装核验**：回“引擎管理”核对官方发行包和安装目录。
   - **清理未确认**：上一次运行的进程还没确认退出。先去“调度与监控”核对；确认任务进程都已退出后，点“我已确认，全部已关闭”。
   - **可以进行手动实测**：可以开始了。
3. 勾选“我了解这会运行真实游戏自动化任务，仅确认本次执行”，再点“开始本次真实任务测试”。
4. VIvian 会先做一次上游状态检查。如果上游还有任务在运行，或者检查不通过，**不会启动**，并显示“安全检查未通过”。
5. 出现 UAC 弹窗时，确认请求管理员权限的程序是 `...\March7thAssistant_full\m7a.exe`，再由你决定是否同意。
6. 运行中可以随时点“紧急停止当前任务”。注意：收到停止回执不等于进程已经退出，请等页面上显示清理结果。
7. 结束后，“上次结果”会显示：执行完成 / 执行失败 / 结果未知 / 清理未确认 / 安全检查未通过。
8. 想再测一次：等“当前状态”回到“可以进行手动实测”，**重新勾选确认**，再点开始。失败后程序不会自动重试。

## 出错时

1. 截图，保存到 `E:\auto agent game\截图反馈\待处理截图`（直接放在 `截图反馈` 里也可以）。
2. 在“真实任务测试”页点“导出诊断报告”。报告会存到 `E:\auto agent game\截图反馈\对应日志`；如果这个文件夹不存在，就存到程序自己的导出目录（页面上会显示具体位置）。报告已脱敏，不含账号、密码或上游配置内容。
3. 告诉 Claude：“截图反馈有新文件了”。

## 判定规则（为什么有时显示“结果未知”）

- 上游退出码是 0，不等于成功。只有本次运行的 39 个界面都逐项切换成功、计数一致，并确认进程已全部退出，才会显示“执行完成”。
- 如果本次运行的上游总结明确写着失败（例如“成功 0 个，失败 1 个”或“测试终止”），会显示“执行失败”，并说明原因，例如账号登录过期。
- 证据缺失或互相矛盾时，显示“结果未知”，不会猜测。
- 进程退出无法确认时，显示“清理未确认”，下一次测试会被阻断，直到核对完成。
