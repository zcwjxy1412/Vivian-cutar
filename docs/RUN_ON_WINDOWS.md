# 在 Windows 上运行 VIvian 开发版（0.4.0-dev）

> **预桌面开发版 · 模拟引擎。** 这个版本**不会**运行任何真实的游戏任务：不启动游戏，不启动 BetterGI、March7thAssistant 或 OneDragon，不读写游戏或引擎的配置。它能做的是：只读检查三个引擎的安装目录、核对星铁官方发行包、保存任务计划，以及用模拟引擎演示调度、紧急停止和结果判定。

## 获取

1. 打开仓库的 Actions → **Windows validation**，进入目标分支最新一次成功的 **push** 运行（PR 运行构建的是临时合并提交）。
2. 在页面底部的 Artifacts 中下载 **VIvian-dev-win-x64**，解压后得到 `VIvian-win-x64.zip`、`VIvian-win-x64.zip.sha256` 和 `BUILD-INFO.txt`。
3. 可选：在 PowerShell 中运行 `Get-FileHash .\VIvian-win-x64.zip -Algorithm SHA256`，与 `.sha256` 文件中的值比对。
4. 把 `VIvian-win-x64.zip` 解压到一个新的空目录（例如 `D:\VIvian`）。
5. 需要 Windows 10/11 x64。这是自包含发布，**不需要安装 .NET**。程序未签名，SmartScreen 可能提示，选择“仍要运行”。

## 第一次使用

1. 运行 `VIvian.exe`。不需要管理员权限，也**不要**以管理员身份运行。
2. **引擎管理**：填写或浏览选择已经安装的引擎目录（可以只填一部分），点“保存路径并检查”。展开“检查详情”可以看到每一项检查和建议，展开“能力与证据”可以看到每项能力的验证状态。
3. **概览**：每个引擎显示一个状态。
   - **文件已核对 · 待桌面验证**：星铁的 `m7a.exe` 与已核对的官方发行包中的文件完全一致。只证明文件来源，**仍然不会运行它**。
   - **待桌面验证**：安装看起来符合固定版本，但启动方式、进程归属与完成信号还没有实测。
   - **不支持（版本）/ 版本未知**：版本不在 VIvian 的证据范围内，或无法读取版本。
   - **未安装 / 未设置路径 / 无法访问 / 目录不安全**（路径超时、无法读取或经过链接）。
4. 可选：在“引擎管理”底部选择从 [March7thAssistant 官方 Release](https://github.com/moesnow/March7thAssistant/releases/tag/v2026.10.31) 下载的 `March7thAssistant_full.zip`，点“核对官方发行包”。只读取文件、计算 SHA-256，不解压、不运行。
5. **任务管理**：选择游戏，勾选和排序候选任务并保存。这些任务都显示“不可执行”，只是计划。
6. **调度与监控**：选择每款游戏的模拟情形，开始队列，随时可以紧急停止。结果都带【模拟】标签。
7. **设置与诊断**：设置日志保留天数；遇到问题时点“导出诊断包”，在导出文件夹中找到 ZIP（已脱敏）。

数据和日志在 `%LOCALAPPDATA%\VIvian`（日志在 `logs`，诊断包在 `exports`）。

## 已知限制

- 真实任务执行没有开放；UAC、提权进程归属、真实引擎行为都还没有在桌面上验证。
- 官方发行包核对只支持 v2026.10.31 的 `March7thAssistant_full.zip`；BetterGI 与 OneDragon 暂不支持发行包核对。
- 不提供安装器、自动更新和托盘。删除解压目录与 `%LOCALAPPDATA%\VIvian` 即可完全移除。
