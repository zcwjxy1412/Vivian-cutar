# VIvian M4-A2 星铁单次实机测试包

本包是 M4-D 的第三个独立单次测试包，**制作包的授权不等于运行游戏的授权；运行前仍需单独确认**。请解压到全新目录，保留 `VIvian-M4A-ScreenTest.marker`，启动 `VIvian.exe`。它使用独立的 `%LOCALAPPDATA%\VIvian-M4A-ScreenTest-R3`，保留前两次尝试的记录，也不覆盖原 VIvian 安装及 `%LOCALAPPDATA%\VIvian` 数据。

1. 在“引擎管理”选择已核对官方发行包的 March7thAssistant 安装目录，并选择官方 `March7thAssistant_full.zip` 核对 SHA-256。不要选择原有 VIvian 的安装目录。
2. 在“星铁实测”确认任务仅为“界面可切换性测试”。它会打开或连接星铁，并切换可达界面；可能写入上游日志、配置、错误截图，账号状态仍可能受界面操作影响。若未准备好，请不要勾选确认。
3. 勾选“仅确认本次执行”后点击启动。点击即用掉此包的单次尝试许可，失败也不会自动重试。程序会先执行上游 `--status`；该命令可能在上游目录创建并删除短暂探测文件。若状态不通过，不会启动任务。
4. 上游任务需要管理员权限，UAC 弹窗由你本人核对程序路径并操作。VIvian 不静默提权。运行中可在“星铁实测”或“调度与监控”点击“紧急停止”。停止回执不代表进程已退出；请等清理状态核对完成。
5. 在“调度与监控”查看本次日志、结果与清理状态。若显示未确认/阻断，不要启动其他任务；按运行记录中的 PID 核对任务进程，必要时由你在任务管理器处理。导出诊断包前请自行查看其中内容。

此包不能自动运行每日实训、清体力、整套日常或其他引擎；任务计划不会触发真实执行。`screen_test` 的完成只证明本次界面切换步骤记录满足校验，**不代表每日实训已完成**。官方上游可能在任务结束后让游戏继续运行。

本地测试及 CI 只证明代码和无害进程路径。真实游戏启动、停止和完成必须以本次实测报告为准；若证据不足，保持结果未知和队列阻断。
