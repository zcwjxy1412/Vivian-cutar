# M5 每日实训 Windows 实测

> 历史验收记录。当前版本的启动、UAC 和多账号步骤见 [M5.2 操作说明](M5_2_DELIVERY.md)。

此开发包只开放 March7thAssistant v2026.10.31 的 `routine`（日常：按原软件配置的副本清体力并借用支援角色 → 每日实训 → 领奖）。2026-11-06 的实测证明单独的 `daily` 不消耗开拓力，最多只能到 300/500。真实游戏和账号操作必须由你本人在自己的 Windows 电脑上确认。CI 与 WPF 冒烟只证明程序构建、自检和模拟流程可用，不能证明游戏任务成功。

固定测试版由开发者部署在 `E:\auto agent game\VIvian\VIvian.exe`，桌面快捷方式“VIvian（开发测试版）”。不需要下载或解压 CI 产物，也不需要填写路径。

## 你需要做的

1. 打开游戏并登录账号；**关闭星铁助手（March7th Assistant）窗口**（运行中的上游程序会让 VIvian 拒绝修改或恢复配置）。
2. 打开 VIvian。首页“星铁 · 每日实训”会自动显示安装核验、配置同步与状态。
3. 勾选“我确认本次真实游戏任务：日常（清体力 + 每日实训 + 领奖）”。开拓力需不少于 120，否则无法达到 500 分。
4. 如果首页出现“允许本次临时修改：…（结束后自动恢复并核对）”，说明你在原软件里关闭了领取奖励、清体力或每日实训中的某项。日常任务需要这三项都开启，勾选它表示只为这一次运行临时开启。
5. 点击“开始本次真实测试”，UAC 弹窗由你本人核对 `m7a.exe` 路径后处理。
6. 观察游戏。结束后首页显示结果、清理状态和临时配置恢复结果。有问题时截图放进 `截图反馈\待处理截图`，告诉开发者即可，日志会自动对应。

## 不再需要的步骤

- **不需要**在原软件中修改“成功后暂停”“失败后退出”。上游 v2026.10.31 的这两个值只控制交互式命令行的“按回车关闭窗口”（`utils/console.py`）；VIvian 每次都以 `--non-interactive` 启动，且 `m7a.exe` 交给管理员 Worker 时也会自动追加该参数（`utils/cli_entry.py worker_command`）。

## 结果判定（以本次 RunId 的输出为准）

| 结果 | 条件 |
|---|---|
| 成功 | 本次输出在“开始日常任务”之后出现领奖完成通知（默认“每日实训已完成”，按你在 `notify_template` 中的自定义文字识别），且没有“每日实训未完成”或“发生错误”；工作进程退出已确认。上游只在找到游戏内 500 分图像并在本次领取奖励后才打印该通知（`tasks/reward/quest.py`）。中途“任务无法完成: …”是上游未实现的子任务，不影响达标判定，会在结果中注明数量。 |
| 失败 | 上游报告失败、错误，或本次核对显示“每日实训未完成”。 |
| 结果未知 | 退出码 0 但没有新的领奖通知：例如今日已领过、领取奖励被关闭、未进入日常任务；或运行编号、终态记录缺失。 |
| 已取消 | 由你停止，且上游记录为停止。 |

## 临时配置的安全规则

- 只修改任务确实需要、且已登记为“可编辑”的字段；写入前先保存恢复记录，写入后读回核对，原文件备份在数据目录 `configuration-audit`。
- 结束后只恢复 VIvian 改过、且仍是临时值的字段；上游运行中写入的时间戳、任务列表等不受影响，不会整体覆盖文件。
- 如果上游仍在运行或字段无法识别，恢复会被拒绝并保留记录，首页显示“恢复临时配置”按钮；下次启动 VIvian 时也会自动重试。未恢复前不能开始新的真实任务。

BetterGI 和 OneDragon 当前只提供任务目录、配置位置与只读状态。OneDragon 多账号实例尚未绑定，不能写入配置或执行真实任务。
