# VIvian M4 三引擎 Windows 集成预览

请解压到新目录，保留 `VIvian-M4-ThreeEngine-Preview.marker` 后启动 `VIvian.exe`。应用使用独立的 `%LOCALAPPDATA%\VIvian-M4-ThreeEngine-Preview` 存放 SQLite、设置与日志，不读取或覆盖现有 VIvian 安装及其他测试包的数据目录。

“引擎管理”可分别选择 BetterGI、March7thAssistant、OneDragon 安装目录并执行只读检查。BetterGI 与 OneDragon 使用各自适配器带来的专用目录和依赖检查；星铁仍可核对固定版官方发行包。检查结果说明文件与环境状态，不代表真实游戏行为已验证。

“任务管理”可保存任务计划；“调度与监控”可运行三游戏模拟队列、紧急停止并查看记录；“设置与诊断”可导出诊断信息。**本预览包关闭所有真实游戏执行**，不会按任务计划启动引擎。星铁单次实机测试须使用另外的独立包和单独授权。

若引擎检查显示路径不可用、版本未知或依赖缺失，请核对所选目录。不要为预览包修改游戏或上游配置。导出诊断资料前请自行检查其中内容。
