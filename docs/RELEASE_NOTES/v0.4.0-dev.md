> ⚠️ **预桌面开发版：模拟引擎 + 只读引擎检查。** 本版本**不包含任何真实游戏自动化**：不启动游戏，不启动 BetterGI、March7thAssistant 或 OneDragon，不读写游戏或引擎的配置，也不操作键盘鼠标。它不是经过验证的自动化发行版。

### 0.4.0-dev 新增

- **三引擎集成框架**：BetterGI v0.66.0、March7thAssistant v2026.10.31、OneDragon v2.6.0 的版本档案（能力、候选任务、启动要求、完成证据契约、已知副作用），每条都标注来源与证据级别。所有能力为“待验证”或“不支持”，真实执行在此版本中始终关闭。
- **统一的只读就绪检查**：三款引擎都显示版本、兼容分类（未设置 / 未安装 / 无法访问 / 目录不安全 / 不支持（版本）/ 版本未知 / 待桌面验证 / 文件已核对）、逐项检查结果与建议。拒绝链接、提示硬链接；OneDragon 检查路径字符规则和受管入口。
- **星铁隔离诊断基础设施**（已实现，执行闸门关闭）：隔离副本、链接/硬链接/路径越界防护、运行前后文件差异、限时与可取消的执行、输出与退出码采集、清理核对、版本/状态解析（使用合成样本测试）、脱敏的证据 JSON。此版本**不运行**任何上游程序。
- **任务管理**：按固定版本列出候选任务，可勾选、排序并保存；全部标为“候选 · 未验证 · 不可执行”。
- **设置与诊断**：日志保留天数、诊断包导出（本地 ZIP，已脱敏，不含数据库、上游配置或账号）、复制日志与导出目录路径、版本与提交号显示。
- **数据库 v3**：任务计划与偏好；旧版本数据库原地升级，失败整体回滚。
- **修复**：读取文件身份（卷号、文件索引、硬链接数）的本机结构体布局错误，使身份比对与硬链接检查可靠。
