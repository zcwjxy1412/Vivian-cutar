# 故障排查

- SDK不匹配：安装global.json中的SDK；不要为了绕过错误随意改目标框架。
- 依赖还原失败：检查是否能访问NuGet官方源；保存artifacts/logs。不要禁用漏洞审计掩盖依赖问题。
- 启动失败：检查%LOCALAPPDATA%\VIvian权限与磁盘空间。若数据库来自更新版本，使用对应新程序；若损坏，先备份，当前版本不会自动删除它。
- 保存提示配置冲突：另一个窗口已经保存。先记下未保存输入，再点击重新加载并重新编辑；不强制覆盖。
- 自检通过但游戏没启动：这是预期行为。0.2.0 仍未接入真实引擎，只有模拟模式。
- 提示“VIvian 已经在运行”：同一个数据目录同时只能运行一个实例。请切换到已打开的窗口；如果找不到窗口，可以在任务管理器中确认是否有残留的 VIvian.exe。
- 提示“无法确认另一个实例的状态”：可能有一个以其他用户或管理员身份运行的 VIvian。为避免冲突，本窗口不会启动。
- “模拟队列”出现红色提示条，无法开始新队列：有运行的清理结果无法确认（或上次 VIvian 意外退出）。确认相关程序都已关闭后，点击“我已确认，全部已关闭”。你的确认会单独记录，不会改写原判定结果。
- 升级到 0.2.0 之后，0.1.0 版打不开数据库：这是正常的保护行为，旧版程序不会覆盖新版数据库。请继续使用 0.2.0。
- Windows冒烟失败：脚本输出测试临时目录，检查其中logs；该测试不用真实用户数据库。
- 高DPI布局问题：保留系统缩放、分辨率及截图用于验收，不能以交叉编译代替视觉测试。
