# 故障排查

- SDK不匹配：安装global.json中的SDK；不要为了绕过错误随意改目标框架。
- 依赖还原失败：检查是否能访问NuGet官方源；保存artifacts/logs。不要禁用漏洞审计掩盖依赖问题。
- 启动失败：检查%LOCALAPPDATA%\VIvian权限与磁盘空间。若数据库来自更新版本，使用对应新程序；若损坏，先备份，当前版本不会自动删除它。
- 保存提示配置冲突：另一个窗口已经保存。先记下未保存输入，再点击重新加载并重新编辑；不强制覆盖。
- 自检通过但游戏没启动：这是M1预览的预期行为，尚未接入引擎。
- Windows冒烟失败：脚本输出测试临时目录，检查其中logs；该测试不用真实用户数据库。
- 高DPI布局问题：保留系统缩放、分辨率及截图用于验收，不能以交叉编译代替视觉测试。
