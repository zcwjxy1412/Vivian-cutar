## 原神本机计划

使用隔离 M6 测试包打开「账号管理 → 原神」。点击「导入登录截图」用本机 OCR 登记显示脱敏标识的原神登录图，也可以选中之前手动建立的档案，再点「为所选档案绑定登录截图」，继续使用原有任务计划。相同登录标识的重复导入会选中原有档案。通过「打开原神配置」进入同一账号的「游戏管理 → 原神」。

「VIvian 本机计划」通过 BetterGI 计划编译器（`8eedb9c`）保存到隔离 SQLite v7。每个新档案的任务默认关闭，启用自动秘境需要名称与明确的树脂次数。保存回读后显示审计编号。计划可离线编辑。

「BetterGI 源档案」按原神账号绑定一个现有的 BetterGI 0.66.0 一条龙档案。绑定信息保存在隔离数据目录的 `genshin-source-bindings.json`。在原神配置页停留时每两秒读回。退出 BetterGI 后，编辑已支持的档案字段会自动写入，运行占用或版本冲突时保留草稿。已映射值在本机计划页只读预览。自动秘境开关与安装级共享树脂设置在 BetterGI 中管理。普通权限可直接打开 BetterGI，管理员隔离版会在 Explorer 中定位程序。源设置当前尚未作为真实调度的输入。

合流源码的「登录验收」沿用同一 `VIvian.exe` 的管理员授权。选一或两个从截图绑定的档案，点击「启动并验收登录」。优先读取 BetterGI 保存的国服路径，驱动核验安装和客户端签名后自动启动或接入。登录验收可通过按钮或 F10 取消，结束后保留客户端。本轮只做离线验证，尚未部署。

## 真实模型复验

1. 首次提升权限前，在普通 PowerShell 运行 [桌面锁初始化](../../scripts/Initialize-M6DesktopLock.ps1)。打开隔离测试包。请在浮窗内填写服务地址、模型名和密钥，点击「测试连接」。成功表示模型已响应并读回本轮验证工具的结果。
2. 保存设置，在隔离档案准备一个已登记的独立星铁账号，选中该账号。先查询星铁游戏与账号状态，再请求读取该账号的配置和生成一项明确提案。确认卡应显示游戏、账号、前值与后值。
3. 点击确认并核对游戏管理页与审计编号。换账号、修改同一份配置或开始运行后，旧提案应失效或被阻断。操作前后核对上游共享文件未被助手写入。
4. 当前工作环境缺少可用真实端点与密钥，以上真实模型往返和确认演示待验。集成记录见 [草稿 PR #57](https://github.com/zcwjxy1412/Vivian-cutar/pull/57)。回环端点和脚本化模型证据已分别记录。确认式 AI 调度先保持默认关闭，待查询与配置闭环实测后再做星铁单账号验收。

原神的提权载荷与账号绑定、绝区零固定实例与受控诊断准入仍待核验。绝区零受监管 `-o` 标准流编码未实测，等证据后再决定是否给单次启动指定解码，其他引擎沿用现有行为。跨游戏真实队列、停止、清理和配置恢复待两款引擎分别取得准入。已验收 M5.2 证据见 [原记录](../M5_2_ACCEPTANCE.md)。
