# VIvian M3 真实引擎集成 UI/UX 增量交互设计规范 (M3_UI_SPEC.md)

> Gemini 原始研究。文中的版本状态、示例和建议保留原貌，实测状态与冲突见[审查记录](../reviews/M3_GEMINI_RESEARCH_VALIDATION.md)。

文档路径：docs/requirements/M3_UI_SPEC.md

设计定位：针对 VIvian M3 阶段接入 BetterGI、March7thAssistant 与 ZZZ-OneDragon 所需的 8 项增量功能界面与交互反馈规范。

核心原则：保持微软 Fluent Design 极简现代风格；所有文案均为符合国人直觉的简体中文；严禁将模拟运行结果伪造为真实游戏结果。

## 1. M3 阶段 8 项核心新增交互规范

### 1.1 三游戏安装状态卡片（Engine Installation Status）

- UI 呈现位置：首页概览卡片顶部 & 引擎管理页
- 三种状态视觉规范：

<!-- -->

- 🟢 已就绪（Installed & Valid）：显示路径摘要（如 D:\VivianWorkspace\engines\BetterGI）、引擎版本（如 v0.66.0）、占用磁盘空间。
- ⚪ 未安装（Not Found）：显示醒目虚线边框卡片，中央放置两个按钮：「一键下载并自动部署」 与 「绑定本地已有目录」。
- 🔴 路径异常 / 命名非法（Path Invalid）：

<!-- -->

- 针对绝区零一条龙：若绑定路径包含中文或空格（如 D:\游戏脚本\ZZZ），立即以红色警示框阻断：⚠️ 绝区零引擎路径包含中文字符，上游 Python 运行时将无法启动。请移至纯英文无空格路径（如 D:\ZZZ-OD）。

### 1.2 引擎版本与兼容性状态指示器（Version & Compatibility Gates）

- 徽章层级与交互设计：

<!-- -->

- 🟢 \[已验证稳定版\]（Verified）：绿色微光药丸标签，点击展示该版本对应的上游 Release 日期及 VIvian 测试通过标签。
- 🟡 \[新版本待验证\]（Unverified）：黄色警示标签。当检测到上游发布了未经兼容性测试的新版时展示。右侧附按钮「查看更新日志」；若用户点击「尝试更新至此版本」，弹出二次确认窗口并提供强制快照备份勾选项。
- 🔴 \[已知不兼容 / 禁止运行\]（Broken）：红色危险标签。展示上游明确的重构风险说明，禁用调度按钮，提示用户回滚。

### 1.3 日常任务开关与预设配置（Daily Task Switches）

- 交互逻辑：

<!-- -->

- 在三游戏任务设置页中，提供直观的 Switch 开关控件。
- 原神：每日委托（历练点）、自动秘境、合成树脂、自动首领、尘歌壶领奖。
- 星铁：每日实训、清开拓力（带副本类型与名称级联选择器）、历战余响、货币战争周常、差分宇宙周常。
- 绝区零：每日签到、录像店营业、咖啡店、体力刷本、活跃度领奖、恶名狩猎。
- 高级设置直通车：在每个游戏卡片右下角提供 「↗ 打开引擎原生配置」，对于小众且复杂的战斗脚本编写、地图路线录制，直接唤起上游的原生图形界面供高级玩家配置。

### 1.4 单游戏独立启动与停止（Single Game Quick Run）

- 操作按钮：每款游戏的概览卡片均配有独立的 「▶ 单独运行日常」 与 「⏹ 强制停止」 按钮。
- 交互互斥约束：当任一游戏正在运行时，其他游戏的「单独运行」按钮自动变为禁用状态，并附带 Tooltip 提示：当前已有游戏任务正在运行，自动化引擎独占前台键鼠，暂不可并发启动。

### 1.5 三游戏任务顺序编排器（Queue Order Reordering）

- 设计形态：位于首页顶部的 流水线编排胶囊条（Pipeline Stepper）。
- 交互方式：

<!-- -->

- 用户可长按鼠标拖拽游戏卡片调整执行先后次序（例如：① 绝区零 ![原文内联图示](../research/assets/gemini-m3/15a864e59603.png) ② 星穹铁道 ![原文内联图示](../research/assets/gemini-m3/15a864e59603.png) ③ 原神）。

### 1.6 任务执行进度与双轨监控（Live Execution Monitor）

- 流水线进度看板（Pipeline Progress）：

<!-- -->

- 当前正在执行的子任务项实时滚动展示（如 原神：正在执行 \[合成树脂\] (第 2/5 步)）。

<!-- -->

- 进程健康度与日志窗：

<!-- -->

- 实时显示当前游戏 PID、引擎 PID、已运行时间 / 超时倒计时。
- 结构化日志窗支持关键字搜索与「自动滚动」。

### 1.7 失败原因展示与智能处理建议（Failure Diagnostics）

- 真实性铁律：严禁伪造测试通过，当任务失败时，界面必须如实展示故障现场。
- 三重视图呈现：

1.  现场快照图：展示任务报错或超时那一刻的系统全屏截图缩略图，点击可放大查看（清晰看清是卡在游戏更新、月卡弹窗还是网络掉线）。
2.  错误定位：自动提取导致失败的核心错误行（如 PaddleOcr预热异常、未找到目标窗口、进程异常退出码: 1）。
3.  排障操作建议：根据已知错误库匹配解决建议（如 检测到游戏小地图未锁定方向，请进入游戏设置设为“锁定方向”），并提供 「重试该游戏」 或 「跳过并进入下一个」。

### 1.8 需要用户手动确认的关键交互（Human-in-the-Loop Dialogs）

1.  三月七小助手首次运行免责声明确认弹窗：

- 触发时机：m7a.exe --status 检测到 first_run_completed: false。
- 弹窗内容：三月七小助手要求首次使用前必须由您本人在原版界面中确认《免责声明》。VIvian 不会代您点击。
- 操作按钮：\[打开三月七小助手完成确认\] 与 \[稍后再说\]。

2.  未经验证版本更新尝试二次确认：

- 弹窗内容：当前版本尚未经过 VIvian 兼容性测试，更新后可能存在接口变更导致自动化中断。是否继续更新？（VIvian 将在更新前自动创建全量回滚备份）。
- 操作按钮：\[我已知晓风险，继续更新\]（勾选后激活）与 \[取消\]。

3.  全局紧急制动反馈：

- 用户在键盘上按下 Ctrl + Alt + F12 时，屏幕中央浮现 1.5 秒红色半透明横幅：⚠️ 已触发紧急制动，已强制挂起并清理所有自动化引擎进程！
