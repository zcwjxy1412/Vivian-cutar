## 视觉定位与边界

- OCR 坐标来自当前游戏客户区物理像素；每次获取窗口位置与大小，DPI 感知，不使用截图的桌面绝对坐标。
- 文本按钮使用当前 OCR 框中心；保留记录选中标记在该文字左侧按文字高度确定的局部区域验证颜色。必须在点击后的新帧重新验证。
- 列表展开以保存行/登录其他账号及垂直布局识别。仅在展开前已经观察到收起卡片的同身份、同位置锚点，且面板布局相符时排除顶部重复卡片；没有锚点时保留歧义并停止选择。真正重复的脱敏身份拒绝选择，行号不构成身份证据。
- 标题页上的欢迎横幅可能形成白色区域，不能仅凭白色面板与手机号识别成登录卡片。
- 遮挡/最小化由输入宿主恢复窗口后重新截图；失败则停止。未知界面只等待，加载使用总时限，有界重试不在未知画面点击。
- 验证码、密码、实名、安全验证、协议等需要本人处理的页面停止批次，不绕过、不自动同意。

## 批次顺序与验收

准备与权限预检 → 读取勾选顺序及配置快照 → 返回登录卡片 → 定位/选择/核对 → 登录并验证连续会话 → 世界就绪 → 日常 → 完成证据 → 上游清理 → 配置恢复 → 下一账号。最后结束游戏与输入宿主，再写批次终态。异常不能把清理未知写成成功。

管理员授权在打开测试版时完成（现有管理员 manifest）；一键日常前必须已提权，批次内不允许再申请 UAC。不安装常驻特权服务、不保存管理员密码、不关闭 UAC。

真实验收：单账号暂停/继续/停止、A→B、三个账号、失败与画面异常、权限与崩溃恢复均须另附实机证据；截图序列与状态机模拟均不能替代。当前参考图只显示两个保存账号，三账号测试条件尚未确认。
