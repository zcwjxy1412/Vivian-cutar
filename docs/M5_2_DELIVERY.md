# M5.2 自动账号切换测试版

状态：代码候选版，真实无人值守验收未完成。不能把模拟切换、参考截图识别或 CI 通过称为 A→B 真机通过。

星铁账号批次从首页启动。请以当前修订版进行 A→B 真机验收。

## 使用

1. 解压到新目录，保留旧包。打开 `VIvian.exe` 时由本人完成 Windows UAC 授权；这是批次前初始化，程序不保存管理员密码、不关闭 UAC、不安装常驻提权服务。关闭程序后重新打开仍由 Windows 决定授权。
2. 在引擎页核验 March7thAssistant 官方发行包与安装目录，预先保存任务配置。未经验证的安装不能执行。
3. 在账号管理点“扫描登录账号”：自动返回保存账号界面，必要时重启已确认身份的游戏，登出时保留登录记录，再展开列表并登记脱敏账号。导入截图仅用于录入参考，实际执行仍核对实时登录卡片。
4. 在账号管理勾选账号并调整顺序。可以点“保存备注和勾选”，首页启动时也会保存当前勾选。
5. 在“游戏管理 → 崩坏：星穹铁道”逐个选账号、保存任务设置。批次开始时冻结各账号的配置。未单独设置的字段沿用启动时读取的星铁助手设置。若勾选的账号关闭了日常，首页会在启动游戏前提示启用任务或取消勾选。
6. 回到首页点一次“一键日常”。程序按账号顺序执行，首页显示进度并提供停止按钮。批次开始前检查管理员授权，逐账号执行期间无需重复确认。各账号结束后恢复临时上游配置，再切换下一个账号。
7. 可最小化 furina；游戏需要可恢复的交互桌面。输入宿主会恢复和置前游戏，并核验点击处窗口归属。无法获取可信截图时安全停止。停止按钮和 F10 均可终止整个批次。

## 执行与保护

- 批次复用已在登录界面或正在启动的星铁客户端。启动请求只发一次，等待窗口出现后再识别。切换账号前会等待旧客户端退出，包括已经关闭窗口但尚未退出的进程。等待超时会停止批次并报告所在步骤。
- 识别使用通过归属检查的桌面画面。登录文字难读时会补读放大的登录框、标题和登出区域。未知画面仅在时限内重试。
- 标题“开始游戏”不是世界就绪。先“登出”，确认“退出并保留登录记录”被选中，再点模态框内“退出”。永不点击清除登录记录或账号行删除按钮。
- 选择目标后必须看到收起卡片中的唯一目标标识；欢迎横幅若可识别也须相符。进程 PID/启动时间的连续性保持到世界就绪；UID 可选，但读到不一致或与上一账号相同即停止。
- 重复脱敏身份不使用历史行号猜测。未知画面不盲点，已知加载有总步数和时间限制。
- 日常完成须有本次运行的证据。支持明确的领奖通知、游戏显示本日活跃度已满且随后没有待领实训奖励，以及同一助手进程的末次 500 分图像核验记录。助手退出码不单独作为完成证据。任务进程清理和临时配置恢复都确认后才切换。
- 任务失败仅在清理和恢复确认后才允许继续。验证码、实名、密码、安全验证、协议确认、宿主断开、身份不确定或配置恢复失败停止批次。
- 最后一个账号结束后确认游戏退出，再关闭输入宿主并保存结果。异常终态写入数据库，不能留在正常运行状态。
- 自动失败诊断写 `login-evidence/*.json`：仅状态、尺寸、PID与脱敏标识，不自动保存原始截图或原始 OCR。旧版已保存的 PNG 不擅自删除，分享前自行审阅。
