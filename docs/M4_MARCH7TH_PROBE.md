# 星铁隔离状态检查（M4-A 准备工具）

1. 保留当前 `E:\auto agent game\VIvian-win-x64` 不动。将本包解压到新目录，以普通用户身份双击“运行星铁状态检查.cmd”。
2. 按提示粘贴 March7thAssistant v2026.10.31 的安装目录和从官方 Release 下载的 `March7thAssistant_full.zip` 完整路径。路径有空格也可直接粘贴。
3. 工具先只读比对官方包 SHA-256 和安装目录 `m7a.exe` 摘要；只有两者一致才允许继续。输入“同意检测”后，它将创建临时独立副本，并仅运行副本中的 `m7a.exe --status`。它不会启动游戏、执行任务或请求 UAC。
4. 把窗口最后显示的“CLI 状态、退出码、清理、耗时、状态检查结论”发回。不要发送包含游戏路径、账号或配置内容的原始输出。

若缺少官方 ZIP，可先从上游正式发行页下载。此工具只验证状态命令与隔离进程边界，**不是 M4-A 真实执行版**。原有 VIvian 设置与 SQLite 不受影响，无需备份或卸载。后续的 UAC 和实际游戏测试须分别确认。
