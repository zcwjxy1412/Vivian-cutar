# M4-A2 无游戏 UAC 归属验证（待用户单独批准）

## 已准备的程序

`VIvian.UacBoundaryProbe.exe` 是独立的 .NET 10 自包含工具。普通权限入口使用 Windows 标准 `runas` 启动它自身的工作进程，系统会弹出 UAC；工作进程再创建一个无害子进程。两者只记录随机运行编号、PID、创建时间、是否提权及父子关系，不操作游戏、键鼠、网络、引擎安装或 VIvian 正式数据库。

入口收到两份记录后创建**本次随机编号**的停止标记。工作进程和子进程读取该标记自行退出；即使入口异常，二者也会在约 40 秒后自行结束。工具只在必要时通过自己持有的子进程句柄结束那个无害子进程，不扫描或结束同名进程。

报告仅写入新建目录 `E:\auto agent game\M4A2-UAC-probe-result`。工具不会修改现有 `VIvian-win-x64` 安装、`%LOCALAPPDATA%\VIvian` 或 March7thAssistant。报告只在本机保留，发送前由用户决定。

## 待批准的实际操作

1. 从普通权限 PowerShell 运行 `E:\auto agent game\VIvian-M4A2-UacBoundaryProbe-win-x64\VIvian.UacBoundaryProbe.exe parent "E:\auto agent game\M4A2-UAC-probe-result"`。
2. 用户本人查看系统 UAC 上显示的程序路径，并决定先点“否”记录拒绝路径，还是点“是”验证提权工作进程。两次测试须分别确认；Codex 不替用户点击 UAC。
3. 若点“是”，工具记录工作进程和子进程的精确身份，发送停止标记，等待退出，并生成 `结果.json`。如果未能确认两者退出，结果为未确认，真实任务闸门继续关闭。可在任务管理器按报告 PID 人工查看；工具不会尝试按进程名结束其他程序。

预期副作用：一次 UAC 提示、最多两个短时测试进程、独立目录下的三份 JSON 和一个停止标记。失败或中途退出时测试进程约 40 秒内自行结束；如果进程仍存在，由用户决定是否通过任务管理器结束对应 PID。

此测试只验证 Windows 跨权限**类比进程**的观测能力，不证明 March7thAssistant 的真实工作进程或日常完成。通过后仍须另行批准上游真实任务及游戏账号操作；在取得本次证据前不开放真实执行。
